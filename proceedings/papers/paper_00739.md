abstract: |-
  Optimization-free object detection dataset distillation has shown that synthesizing training data by cropping real instances and densely collaging them can produce effective distilled detection sets without pixel-level optimization. Existing canvas assembly methods, however, are still largely driven by sequential candidate traversal and random overlap-constrained placement. They therefore increase per-image instance density without explicitly controlling class co-occurrence or relative spatial arrangement, which can lead to context-mismatched object combinations and implausible local layouts under extreme compression.

  We propose Statistical Prior-guided Dense Assembly (SPDA), a front-end assembly strategy for optimization-free object detection dataset distillation. SPDA uses class-conditional priors over ordered instance pairs to choose the next category from a category-indexed global object pool, and then uses relative spatial preference maps to rank candidate placements around already placed instances. To avoid repeatedly overfilling a single local region, it further grows multiple dense local clusters within the same canvas instead of relying on a single random placement stream. The method requires neither an additional generator nor pixel optimization, and remains compatible with the standard OD3 observer-screening and post-training pipeline. On COCO, SPDA attains mAP scores of 14.9\%, 18.9\%, and 22.6\% at 0.25\%, 0.5\%, and 1.0\% compression, respectively.
