abstract: |-
  Sparse query-based 3D detectors commonly encode heterogeneous semantic, geometric, and motion information into unified latent queries, including when explicit 3D anchors are used.
  We introduce ExQuery, an explicit structured query framework for temporal 3D object detection.
  Each decoded query is organized into a shared semantic-context slice and physical-state-specific slices for center, dimensions, orientation, and velocity.
  This structure is preserved from prior encoding to branch-specific regression and is reused to reconstruct temporal queries: predicted physical states are transformed by ego motion, classification scores form soft semantic priors, and the reconstructed query is fused with the stored latent instance feature through gated affine modulation.
  Experiments on the nuScenes benchmark show that our method achieves competitive detection performance, and ablation studies validate the effectiveness of our proposed modules.
