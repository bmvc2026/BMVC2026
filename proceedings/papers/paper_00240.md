abstract: 'Composed Image Retrieval (CIR) requires models to retrieve images that match both a reference image and a textual instruction, posing significant challenges in compositional reasoning and cross-modal alignment. While recent zero-shot CIR (ZS-CIR) methods leverage text inversion to bridge vision and language, they often encode the reference image into holistic, entangled representations, making it difficult to selectively manipulate static properties versus functional semantics. In this work, we tackle this challenge by an explicit disentanglement of visual representations into their fundamental concepts: attributes and affordances. Our novel framework leverages vector-quantized codebooks to learn a discrete semantic vocabulary for each of these concepts. Then, these concept codes are dynamically modulated by an instruction-aware conditioning module, generating a query embedding precisely aligned with the editing intent. Experiments demonstrate that our method achieves state-of-the-art performance on CIR benchmarks.'
