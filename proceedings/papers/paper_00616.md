abstract: |-
  RGB-Infrared (RGB-IR) object detection improves perception robustness under complex illumination conditions, but deploying RGB-IR detectors on edge devices faces two practical challenges.
  First, RGB-IR detectors must process dual-modal inputs under limited computation, memory, and latency budgets.
  Second, practical edge systems often require flexible accuracy-latency trade-offs under changing workloads, whereas existing RGB-IR detectors usually operate at a fixed input resolution and computational cost, offering only a single operating point and limited deployment flexibility.
  To address these challenges, we propose EM-Mamba, a lightweight resolution-elastic RGB-IR object detector that provides multiple deployment modes using a single set of model weights.

  EM-Mamba is built on a Mamba-based Vision State Space Fusion Block (VSSFusionBlock), which integrates Multi-scale Depthwise Convolution (MDwConv) for local multi-scale detail enhancement, Cross-modal 2D Selective Scanning (SS2DFusion) for unified RGB-IR state propagation, and a Depthwise Feed-Forward Network (DwFFN) for lightweight spatial-channel refinement.
  To support flexible inference at different input resolutions, we further propose Multi-Resolution Consistency Learning (MRCL), a structured training strategy that combines multi-resolution joint optimization with high-to-low resolution feature and logit consistency.
  In our experiments, MRCL improves cross-resolution performance and is more reliable than naive random multi-resolution training for the studied Mamba-based detector.

  Extensive experiments on M3FD, LLVIP, and KAIST show that the same 5.9M-parameter EM-Mamba model provides multiple operating points, reaching 91.2% mAP$_{50}$ at $960 \times 960$ and 23.6 ms latency at $480 \times 480$.
  These results suggest that EM-Mamba is a practical option for edge-oriented RGB-IR object detection when both efficiency and deployment flexibility are important.
