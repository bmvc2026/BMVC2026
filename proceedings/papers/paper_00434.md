abstract: Traditional object detectors are restricted to closed vocabularies and therefore struggle to recognize novel categories at test time. Emerging open-ended detection frameworks aim to assign meaningful names to previously unseen objects, yet most rely solely on visual matching or free-form captioning without verifying the semantic plausibility of their predictions. We introduce a self-refining framework for open-ended object detection that unifies detection, language reasoning, and generative refinement. Our pipeline combines known-object detection and unknown-region segmentation to extract unknown regions and scene context. For each unknown region, we extract text descriptors and combine them with the scene context to prompt a Large Language Model (LLM) to generate a ranked list of candidate class names. We then re-rank candidates by visual similarity to the unknown region, and store the resulting predictions in an Embedding-Label Repository (ELR), which serves as a memory that exploits evidence accumulated across repeated encounters with the same object. To reduce hallucinations, we add diffusion-generated confusion anchors from second-ranked LLM predictions. Once the ELR reaches sufficient coverage, we apply iterative k-NN label refinement to improve semantic consistency. Our method requires no task-specific training and no vocabulary supervision, yet it achieves state-of-the-art results on COCO and LVIS for novel and rare categories. These results demonstrate that language-driven reasoning combined with generative expansion substantially improves open-ended object detection.
