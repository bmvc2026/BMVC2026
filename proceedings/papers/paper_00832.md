abstract: Oracle Bone Script (OBS) recognition is uniquely challenging due to ultra-thin strokes (2–5 pixels), fine-grained distinctions where a single vertical stroke separates two characters, and pervasive noise from cracks and rubbing artifacts. This fine-grained recognition task requires models with adaptive receptive fields and structural priors. Generic Vision Transformers lack adaptive receptive fields, are distracted by background artifacts, and ignore radical-level structural priors. To address these limitations, we propose Topo-Swin, an efficient Swin Transformer architecture with three novel components. First, Adaptive Window Aggregation (AWA) dynamically selects and aggregates window sizes based on local stroke density, avoiding feature aliasing in dense regions while reducing computation in sparse areas. Second, Prototype-Guided Attention (PGA) constructs unsupervised structural prototypes via K-Means and injects them as attention biases, enabling the model to focus on discriminative stroke structures and suppress background noise. Third, Multi-Scale Feature Fusion (MSFF) employs parallel atrous convolutions and a bidirectional feature pyramid to balance fine-grained stroke details with global topology. On the HUST-OBC benchmark, Topo-Swin achieves 84.6% Top-1 and 88.1% Top-10 accuracy, outperforming prior state-of-the-art methods including LVLM-based approaches, while using only 30.2M parameters and 4.5ms inference latency. Ablations validate each component, and visualizations confirm domain-aligned feature learning. Topo-Swin offers an accurate, efficient, and interpretable solution for fine-grained ancient character recognition.
