abstract: 'Recent learning-based methods have advanced zero-shot point cloud registration, but low-overlap scenes remain challenging because non-overlapping regions, repeated structures, and planar redundancy can produce misleading consensus. Existing multi-scale consensus mechanisms often rely on candidate inlier counts, which do not distinguish informative from redundant support. To address this issue, we propose SAFE-Reg, a Structure-Aware Failure-Evading Zero-Shot Point Cloud Registration method for lowoverlap scenes. SAFE-Reg introduces two structure-aware modules: Structure-guided Descriptor Routing selectively injects reliable local details into global descriptors, while Ambiguity-aware Hypothesis Re-ranking suppresses high-consensus hypotheses supported by ambiguous and redundant structures. The full system also uses an enhanced robust estimator for final pose verification and refinement. Experiments show that SAFEReg improves low-overlap registration recall while preserving zero-shot generalization behavior. Our code is available at https://github.com/0xhr/SAFE-Reg.'
