abstract: Deep learning models for digital histopathology require extensive fine-grained annotations. While active learning reduces labeling effort, it assumes a closed-set setting and struggles when unlabeled data contains abundant non-target tissue. We propose DF-OSAL, a diversity-aware open-set active learning framework that leverages a foundation model and an asynchronous candidate queue for efficient querying. DF-OSAL performs global clustering to ensure broad morphological manifold coverage and progressively increases clustering granularity across query rounds to capture subtle data variations. Unlike prior methods that rely on proximity-restricted candidate sets and uncertainty measures, which can be unstable in early rounds and limit exploration, DF-OSAL promotes balanced global exploration. Across three histopathology benchmarks, DF-OSAL achieves faster convergence and improved annotation efficiency, approaching fully supervised performance with fewer labeled samples.
