abstract: 'Dense few-shot recognition typically treats matching as a set of independent class queries. Each candidate class is free to construct its own isolated explanation of the query image. In difficult cross-domain episodes, this independence becomes a liability: ambiguous local structures, repeated textures, and background clutter can be copied across competing labels, allowing multiple classes to claim the same visual evidence. We argue that the missing ingredient is competition: query evidence should be allocated, not duplicated. We introduce Region-Gated Competitive Transport (RGCT), a training-free few-shot classifier that turns dense matching into an episode-level competition for patch ownership. RGCT optimizes a latent allocation field over the query image, assigning each patch to one candidate class or to a dedicated reject state for non-diagnostic evidence. Each class then solves a semi-relaxed optimal transport problem using only the patch mass it owns, while a feature-weighted spatial prior encourages visually similar neighboring patches to form coherent regions. The final RGCT decision energy combines this allocated local transport cost with image-level semantic compatibility from the same frozen encoder. The local term is a competitively gated transport cost over the query evidence routed to each class, not an independent per-class dense score, so candidate labels compete for the same patch budget instead of reusing it. On BSCD-FSL, RGCT achieves 67.17% average 5-way 5-shot accuracy, outperforming the strongest dense training-free baseline, DN4, by 3.02 points and surpassing standard prototype matchers by up to 3.35 points. Despite using no episodic training, source-domain adaptation, or backbone updates, RGCT outperforms 9 of 11 adaptation and fine-tuning entries in the main BSCD-FSL comparison, establishes a new overall state of the art on EuroSAT at 93.54%, and ranks second overall on ChestX. The same competitive formulation also transfers beyond cross-domain recognition, reaching 98.63% on miniImageNet and 94.45% on tieredImageNet. Code: https://github.com/AhmedMostafaSoliman/RGCT/'
