abstract: 'Referring Multi-Object Tracking (RMOT) localizes all objects described by a language expression and preserves their identities across frames. A recurring failure arises when an occluded target is surrounded by visually similar objects: a propagated track query can attend to a language-compatible distractor, write this evidence into its state, and drift toward the wrong identity in subsequent frames. We propose DriftGuard, a state-safe RMOT framework that protects each trajectory in both the read and write steps. For each active trajectory, DriftGuard maintains a language-conditioned state, routes visual tokens using static and motion language cues together with the previous track state, and learns counterfactual separation between target evidence and identity-inconsistent distractors. A query-quality gate suppresses temporal writes from unreliable predictions. On Refer-KITTI and Refer-KITTI-V2, DriftGuard delivers competitive tracking performance and improves association quality over our TransRMOT-based query-propagated baseline, while reducing identity switches with limited change in detection accuracy.'
