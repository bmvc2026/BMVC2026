abstract: |-
  LiDAR-camera 3D object detection benefits from dense image appearance cues, but
  projection-based fusion remains sensitive to occlusion-induced color contamination. We
  propose HC-MVMM, a hierarchical confidence-guided extension of the Multiview Mul-
  timodal 3-D Object Detection (MVMM) framework for occlusion-aware LiDAR-camera
  fusion. At the point level, HC-MVMM assigns image evidence to directly visible Li-
  DAR returns and estimates confidence for hidden or weakly supported points. At the
  voxel level, it aggregates point confidence into voxel features to reduce the effect of un-
  reliable painted points. At the BEV level, it uses the confidence map to guide deformable
  feature enhancement, so image evidence is emphasized where it is reliable. On the KITTI
  test set, HC-MVMM improves the MVMM baseline by 4.59 AP for Pedestrian and 3.08
  AP for Cyclist on the Moderate 3D metric, while maintaining competitive Car perfor-
  mance. These results show that hierarchical confidence modeling is an effective and
  interpretable way to improve LiDAR-camera fusion under occlusion. Code is available
  at https://github.com/lancez1225/HC-MVMM.
