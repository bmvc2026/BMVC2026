abstract: |-
  Logical anomaly detection in machine vision---automatically identifying violations of constraints such as missing components, incorrect counts, or mismatched attributes---requires relational reasoning over scene structure, unlike methods that detect only local pixel-level deviations. Recent few-shot methods that provide explanations rely on a vision-language model (VLM) for every test image, incurring API costs, inference latency, and inconsistent outputs across runs, which limit reliable deployment.

  We present SyCLAD, a few-shot logical anomaly detection framework based on symbolic constraints, in which a VLM is called once offline per product category to automatically extract a structured set of symbolic constraints that encode the normality rules of that product. All subsequent inference is fully deterministic, using only semantic segmentation masks and CLIP (Contrastive Language--Image Pre-training) visual prototypes with no further VLM calls. Every detection produces a reproducible, quantitatively grounded explanation that reports the violated constraint, the responsible component, and its measured deviation from the calibrated normal range, or any attribute mismatch.

  On the MVTec LOCO benchmark at 4-shot, SyCLAD achieves 93.4% image-level AUROC on the logical anomaly split and 85.7% on the combined evaluation.
