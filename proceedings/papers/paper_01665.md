abstract: |-
  Weakly supervised affordance grounding seeks to localize action-enabling object regions without pixel-level affordance annotations.
  Recent methods learn from exocentric human-object interaction images and transfer the resulting affordance cues to egocentric targets, but this transfer is built on a fragile assumption where demonstrations of the same affordance should expose a stable visual commonality. In practice, exocentric examples vary substantially in viewpoint, object scale, and scene context, while the target egocentric view follows a different visual distribution. This dual heterogeneity encourages models to bind affordances to incidental visual correlations rather than to the object parts that actually support an action. While visual commonality can be unreliable, prompt-conditioned affordance semantics provide a compact and explicit cue shared across demonstrations and targets, making them a natural semantic affordance anchor. Motivated by this observation, we propose $\textbf{W}$eakly supervised $\textbf{A}$ffordance $\textbf{G}$rounding with $\textbf{D}$ual $\textbf{S}$emantic guidance ($\textbf{WAGDS}$), a lightweight dual-branch framework that instantiates this anchor with affordance labels and learnable context prompts to canonicalize exocentric and egocentric features into a common affordance space. Its core DSAG block consists of semantic-driven visual alignment, visual stream injection, and CAM localization, with a recurrent egocentric feature path that turns noisy demonstrations into transferable affordance evidence.
  Experiments on AGD20K and HICO-IIF show that WAGDS is competitive with recent weakly supervised affordance grounding methods while remaining simple and parameter-efficient. Qualitative analyses further show that semantic anchoring improves localization of action-relevant object parts under large appearance and viewpoint changes.
