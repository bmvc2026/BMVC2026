abstract: |-
  We propose a novel method for 6D object pose estimation from RGB images. In contrast to traditional instance-level approaches, which rely on object-specific 3D models and per-instance training, our method does not require explicit 3D models during either training or inference. Instead, the only 3D information used at test time is the size of the minimal enclosing 3D bounding box, which defines a representative 3D ellipsoid for each object instance or even for an entire category, assuming limited intra-class size variation.
  During training, the method requires only minimal enclosing oriented 2D bounding boxes (OBBs), object category labels, and object orientations, without the need for segmentation masks or translation annotations. To recover the full 6D pose, objects are modeled as 3D ellipsoids and matched to their projected 2D ellipses, directly inferred from the predicted OBBs. Given this 3D–2D correspondence and the predicted rotation, the object translation is computed analytically in closed form.
  Our neural network learns to infer the ellipsoid–ellipse correspondence directly from RGB input by predicting object category, OBB parameters, and 3D orientation. This enables real-time detection of multiple objects and estimation of their metric 6D poses in cluttered scenes within a single forward pass.  Extensive experiments demonstrate robust performance in real-world environments and state-of-the-art results on multiple BOP benchmark datasets. Code available: https://github.com/amstadtzita/E2Pose.
