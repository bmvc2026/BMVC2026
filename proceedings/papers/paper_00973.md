abstract: 'Occluded pixels present a fundamental challenge for optical flow: once a region disappears behind a moving foreground object, there is no photometric evidence for its displacement, and temporal memory becomes the only available signal. Yet the context encoders of existing multi-frame methods process each frame independently. We address this gap with OAEFlow (Occlusion-Aware Encoder Flow) which introduces three modules into the context encoder: a Stateful Context Encoder (SCE) that accumulates temporal state across frames, a GRU Decoder Feedback (GDF) block that routes a smoothed decoder uncertainty  signal back to the encoder, and an Occlusion Feedback Module (OFM) that gates context features using both signals to direct memory retrieval toward persistently uncertain locations. We show that EPE for unmatched regions can be misleading in challenging persistent occlusions. We introduce OcTM (Occlusion Tracker Metric), a duration-stratified evaluation metric that tracks connected occluded regions as temporal entities and stratifies end-point error by occlusion persistence. OcTM reveals that recurrent memory models exhibit a monotone improvement pattern over two-frame baselines---benefit grows proportionally with occlusion duration---while two-frame models do not. Our OAEFlow results satisfy this monotone hypothesis with improvements concentrated at medium and long occlusions where the GDF feedback signal is most informative.'
