abstract: Panoramic room layout estimation recovers the layout structures of indoor scenes from 360-degree images. Existing methods adopt compact structured layout representations to improve algorithmic efficiency, and introduce multi-view geometry to enhance layout estimation accuracy. However, they remain susceptible to semantic interference from non-layout structural elements such as furniture, while also relying on externally annotated camera poses. In this work, we propose SSE-Layout, a semantic-aware structural enhancement method to address these limitations. Specifically, we first propose a multi-view Transformer-based framework to exploit multi-view geometry and improve layout estimation accuracy without requiring external camera poses. Then, we contribute a prototype-guided structural enhancement module to extract layout-relevant semantic features from the original feature maps. Furthermore, we propose a semantic-aware compression module to preserve the layout-relevant structural semantics in a compressed 1D feature sequence. Finally, we conduct extensive experiments that demonstrate our method consistently outperforms existing panoramic layout estimation approaches across multiple benchmarks.
