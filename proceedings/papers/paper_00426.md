abstract: Reconstructing 3D objects from EEG signals is challenging because neural evidence related to object geometry and appearance is weak, spatially distributed, and highly variable across trials. Existing EEG-to-3D methods typically use EEG embeddings as fixed-strength generation conditions, which can cause unreliable neural responses to dominate the reconstruction process and degrade both geometry and appearance. In this work, we propose LoNR-3D, a reliability-aware neural conditioning framework for EEG-guided 3D object reconstruction under low-SNR neural observations. LoNR-3D treats EEG not as a deterministic condition, but as uncertain neural evidence whose spatial support and generation strength should be explicitly modeled. First, we introduce a spatial-prior-constrained EEG encoder that restricts cross-channel interaction to physiologically plausible electrode neighborhoods, enabling weak but consistent visual responses to be aggregated while suppressing unreliable global propagation. Second, we design a static-guided dynamic residual fusion strategy, where static EEG serves as a stable object-level anchor and dynamic EEG provides complementary viewpoint-induced geometric cues. Third, we propose a reliability-aware reconstruction strategy that estimates sample-level shape and appearance confidence from EEG prediction distributions and adaptively balances EEG-derived evidence with prototype geometry priors for point cloud generation and color prediction. Experiments on EEG-3D show that LoNR-3D consistently improves object decoding, color prediction, and point-cloud reconstruction quality over existing EEG-to-3D baselines.
