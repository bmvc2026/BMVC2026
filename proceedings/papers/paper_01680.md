abstract: |-
  Transformer-based trackers with autoregressive token memory, such as LMTrack, achieve strong performance by selectively retaining informative tokens across frames. However, their inner-product-based memory scoring is sensitive to scene-dependent feature drift: global appearance shifts from lighting changes, camera auto-exposure, and background clutter perturb token norms and angular distributions, degrading memory selection quality. We quantify this fragility directly at the token level and propose Quotient-Space Token Context Memory (QS-TCM), a training-free, inference-time module that estimates dominant centered background-variation directions from spatial background tokens and applies a controlled low-rank attenuation before computing memory affinity. QS-TCM introduces zero additional trainable parameters, uses a lightweight dual Gram-matrix decomposition, and maintains real-time throughput ($55$ FPS baseline versus $51$ FPS on a single NVIDIA A6000). For the projected branch, we show exact invariance to an additive perturbation component lying in the estimated span at full projection ($\alpha{=}1$), and $(1-\alpha)^2$ scaling of that component's pre-softmax logit contribution for $\alpha{<}1$. Because the final score blends raw and projected post-softmax affinities, we do not claim invariance of the consumed
  affinity. Evaluated across six major single object tracking benchmarks using a strictly frozen configuration, QS-TCM consistently improves the strong LMTrack and ODTrack baselines while adding zero parameters and requiring no retraining.
  The code is made public at: https://github.com/omar-ashinawy/QSTCM.
