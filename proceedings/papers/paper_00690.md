abstract: Test-Time Training (TTT) for 3D point cloud classification has become a crucial task due to the challenges posed by distribution shifts and noisy data in real-world computer vision applications. Existing methods rely on memory-intensive decoders and complex auxiliary tasks that increase computational overhead. We present RL-TTT, the first Reinforcement Learning (RL)-based framework for 3D point cloud TTT. By utilizing a novel decoder-free architecture that enables highly efficient gradient updates in standard TTT setting and an entirely backpropagation-free strategy in online TTT, RL-TTT significantly reduces memory footprint compared to current State-Of-The-Art (SOTA) baselines while delivering competitive accuracy. Our lightweight agent dynamically selects the most informative tokens based on object structure, bypassing heavy auxiliary branches. Extensive evaluations on ModelNet-40C, ShapeNet-C, and ScanObjectNN-C demonstrate that RL-TTT redefines the efficiency-accuracy trade-off, achieving adaptation speeds exceeding 6000 FPS with a fraction of the memory cost of prior methods, making it ideal for real-time resource-constrained edge deployments.
