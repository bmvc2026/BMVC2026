abstract: |-
  This paper addresses affordance segmentation in 3D scene point clouds, an essential capability for real-world AI agents that need to identify where physical interactions can occur in a scene.
  Unlike object-centric settings with isolated object point clouds, this scene-level task is challenging because it requires localizing small interaction-relevant object parts within point clouds containing multiple objects and background clutter.
  Existing 3D scene understanding methods often lack sufficient part-level localization accuracy and respond to broad object or scene regions when queried with affordance words.
  Our pilot experiments on existing open-vocabulary 3D scene features reveal a critical finding: although these features already contain useful part-level evidence that enables accurate localization with object-part queries, affordance-term queries often fail to localize the corresponding parts.
  This motivates our central idea: an affordance can be better represented by a diverse set of object parts that support the corresponding interaction than by the affordance word alone.
  Based on this idea, we introduce a part-aware prompt adaptation method that uses object-part terms as linguistic supervision for learning affordance prompts.
  For each affordance, a large language model generates candidate physical components, and the affordance prompt is optimized to align with their text embeddings while keeping both the text encoder and 3D point features fixed.
  Experimental results demonstrate that our method improves 3D scene affordance segmentation, increasing the baseline performance from 8.5 to 9.8 mIoU and from 14.1 to 27.1 mAcc, despite requiring no additional 3D training data or point-wise annotations.
