abstract: Domain-incremental learning aims to adapt models to evolving data distributions while preserving performance on previously seen domains. This is a challenging problem in visual recognition and is particularly relevant to real-world applications such as remote sensing, where domain shifts arise from changes in region, acquisition conditions, or environment. Existing parameter-efficient methods exploit pretrained models and typically rely on learned parameter selection or fixed task-level merging, which can select suboptimal parameters or lose domain-specific information under evolving domain shifts. We propose T-TIME, an approach that incrementally learns lightweight domain-specific adapters and classifiers and dynamically composes their parameters at test time, preserving domain-specific components rather than consolidating them into a single fixed model. T-TIME estimates domain statistics in the pretrained feature space and uses distance-based weighting for sample-wise adaptation, avoiding both single-adapter selection and learned routing mechanisms. Experiments on remote sensing and standard vision domain-incremental learning benchmarks show that T-T IME and its variants achieve state-of-the-art performance without storing or replaying previous-domain data. The code is available at https://github.com/Lamoe291/TTimeDIL.
