abstract: Screenshot-to-Code aims to generate executable front-end code from user interface screenshots. Multimodal large language models (MLLMs) have significantly advanced this task, yet preserving private visual assets remains a persistent challenge. Generated interfaces often reproduce the overall layout and text of an input screenshot while replacing custom icons with generic symbols, approximate drawings, or placeholders. We characterize this failure mode as the Visual Asset Gap and propose Asset-Grounded Screenshot-to-Code (AGSC), a framework that treats visual assets as reusable rendering primitives rather than content to be synthesized by the language model. AGSC extracts assets from the screenshot, represents them in a structured manifest, and guides code generation to reference the original asset files. With IconSeg, a SAM-based UI icon segmentation model, AGSC improves asset-level fidelity on our end-to-end benchmark, raising IR-DICE from 0.49 to 0.88 over direct MLLM generation and improving global SSIM from 0.77 to 0.87. Consistent gains across MLLM backends validate AGSC as a general solution for visually faithful UI code generation.
