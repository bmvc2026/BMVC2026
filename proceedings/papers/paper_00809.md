abstract: Enhancing images captured under low-light conditions on edge devices is challenging because extremely compact models often struggle across very different lighting conditions. Existing lightweight methods mainly predict RGB pixels directly using fixed network designs, which limits restoration quality at very small parameter budgets. We propose ChromaIter, a lightweight iterative enhancement network with only 3.5K inference parameters that progressively refines images in log-YUV space instead of restoring RGB values directly. This separates illumination from color and improves brightness correction. The refinement process is performed using a single weight-shared IterBlock applied over T=4 iterations to improve restoration quality without increasing the parameter count. To improve feature diversity while keeping the model compact, we introduce stochastic weight perturbation with diversity enforcement (SWP-DE), where multiple branches are fused during inference for efficient deployment. On LOLv1, ChromaIter outperforms the strongest compact baseline while using 12% fewer parameters. It also generalizes well to LOLv2-Real without retraining, improving PSNR by 3.79 dB over the same baseline. We further deploy the proposed model in real time on a UAV platform equipped with an onboard Jetson Orin computer for low-light enhancement and YOLO-based person detection under near-zero visibility conditions.
