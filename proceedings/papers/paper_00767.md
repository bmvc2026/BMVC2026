abstract: Temporally consistent depth estimation is necessary to construct precise omnidirectional 3D reconstruction. Although existing omnidirectional stereo matching (OSM) methods have demonstrated high depth estimation accuracy, their per-frame processing paradigm limits the generation of temporally consistent omnidirectional depth predictions. In this paper, we propose TC-Omni, the first OSM framework that predicts temporally consistent omnidirectional depth from sequential inputs. The proposed framework consists of three key modules. The multi-view context enhancement module enriches the context representation by integrating rich multi-view information into the RAFT-based update process. The temporal context enhancement module and temporal correlation learning module further enhance spatio-temporal representations in context and correlation features, respectively. In addition, the proposed confidence-based temporal gradient matching loss enables stable temporal consistency improvement by encouraging the model to learn temporal depth variations from reliable regions. Experimental results on both synthetic and real-world sequential datasets demonstrate that TC-Omni achieves state-of-the-art performance and validates the effectiveness of the proposed method. Code is available at https://github.com/Jmyeong/TC-Omni.
